# Jev Router — Model Routing for Hermes Agent

GitHub: https://github.com/HinkoK/hermes-jev-router
MIT, 2 stars. Plugin for Hermes Agent.

> **Полный разбор**: `/root/kb/projects/jev-router.md`

## What It Is

Плагин для Hermes Agent. Сам выбирает модель по сложности каждого сообщения:

| Задание | Модель |
|----------|--------|
| Лёгкое (привет, факт, перевод, опечатки) | GPT-6 Luna / DeepSeek V4 Flash |
| Среднее (пост, письмо, план, объяснение, обычный код) | GPT-6 Sol |
| Сложное (debug, дизайн системы, деньги/налоги/риски, математика, большой код) | GPT-6 Astra |

## Как решает Джев

За ~0.3 секунды отвечает на 5 вопросов о сообщении:
1. Какой уровень нужен (выбор из трёх, с правилами)
2. Сколько нужно думать (нисколько / обычно / глубоко)
3. Продолжает ли прошлую задачу
4. Просит ли работы с проектом/файлами/командами
5. Дорого ли обойдётся незаметная ошибка (деньги, закон, здоровье, безопасность, прод)

**Правило:** занизить уровень хуже, чем завысить. Шкала и сигналы могут только поднять уровень. Для лёгкого нужно согласие двух ответов.

Стоимость решения: ~$0.00006 (примерно $1.8 на 30,000 сообщений).

## Точность

Проверено на 241 сообщении:

| Точность | Занизил | Сложное → Luna | Завысил |
|----------|---------|----------------|--------|
| jev-router | **95.8–97.5%** | 0–1 из 120 | 3–4 из 120 |
| Простой роутер | 65% | 24 из 120 | 18 из 120 |

Ловушки: «короткий, но сложный» — 12/13, «длинный, но простой» — 11/12, продолжение разговора — 25/27.

Почти все ошибки — в безопасную сторону (лёгкое → средняя модель).

## Установка

```bash
# В ChatGPT: enable
# В Hermes: /router on
```

Ключ: `OPENROUTER_API_KEY` или `TYPESAFE_API_KEY` в `~/.hermes/.env`

Модель чата должна быть одной из трёх уровней (GPT-6 Sol по подписке).

## Команды

| Команда | Что делает |
|---------|-----------|
| `/router on` | Джев выбирает уровень для каждого сообщения |
| `/router off` | Роутер выключен |
| `/router light` · `standard` · `heavy` | Закрепить уровень |
| `/router log 10` | Последние решения: уровень, модель, время |
| `/router check 10` | Какая модель реально ответила |
| `/router stats 50` | Доли лёгких/средних/сложных + сравнение стоимости |
| `/router status` | Текущие настройки |

Терминал: `hermes jev-router on`, `hermes jev-router log 10`, `hermes jev-router route "текст"`

## Настройки

`hermes config set plugins.entries.jev-router.settings.<ключ> <значение>`

| Ключ | Default | Смысл |
|------|---------|-------|
| `models` | см. таблицу | Свои модели |
| `show_model` | `true` | Строка «Ответила: …» под ответом |
| `log_text` | `false` | Хранить текст сообщений в журнале |
| `heavy_at` / `light_at` | `0.45` / `0.55` | Пороги решения |
| `skip_platforms` | `[cron]` | Где не роутить |
| `timeout_s` | `4` | Сколько ждать Джева |

## Приватность

Текст сообщения (до 12,000 символов) и 4 прошлые реплики (по 400 символов) уходят в Джев. Журнал решений локальный, по умолчанию не хранит текст.

## Особенности ChatGPT подписки

- Нет отдельного счёта по запросам
- `/router check` сверяет модель по ответу сервера
- Подписка не принимает скрытые рассуждения одной модели в запросе к другой — роутер убирает рассуждения прошлых ходов при смене модели

## Key Patterns

1. **Model routing by complexity** — не одна модель на всё, а выбор по задаче
2. **Cheap router model** — маленькая модель решает, какая большая ответит
3. **Safety-first bias** — лучше завысить, чем занизить
4. **5 narrow questions** — не один вопрос, а несколько узких
5. **Context-aware** — учитывает прошлые реплики («да, делай»)
6. **Timeout fallback** — если роутер не ответил за 4 сек, отвечает модель чата
7. **Transparent logging** — уровень, модель, время каждого решения
8. **Cost comparison** — сколько стоило бы всё на одной модели
