# Map deeplinks: "как проехать"

Кнопки «Как проехать» в карточке организации. Оба сервиса принимают координаты,
но форматы разные — и оба ломаются молча, если перепутать порядок.

## When to Use

Строишь ссылку «как проехать» / «построить маршрут» в карточке организации,
мини-приложении или сайте — на 2ГИС, Яндекс Карты или любой сервис с deeplink.
Ссылка открылась, но точка не выставлена — это формат, читай раздел про 2ГИС.

## 2ГИС — актуальный формат

```
https://2gis.ru/directions/points/|<lon>,<lat>
```

- `lon` **первый**, потом `lat`.
- `|` в начале — обязательна (это пустая точка А, маршрут от текущей геолокации).
- В начале пути можно указать город: `https://2gis.ru/irkutsk/directions/points/|...`

**Проверено 2026-10-24:** открывает страницу «Маршруты» с распознанным
населённым пунктом и построением маршрута.

### Формат, который больше не работает

```
https://2gis.ru/routeSearch/to/<lon>,<lat>/go     ← 404 page not found
https://2gis.ru/routeSearch/<lon>,<lat>/go         ← 404
```

`routeSearch/.../go` — legacy (использовался до 2020). Отдаёт **404**, и выглядит
как «ссылка не работает», хотя координаты правильные. Именно эта ошибка даёт
симптом «открывается 2ГИС, но точка не выставлена».

## Яндекс Карты — актуальный формат

```
https://yandex.ru/maps/?rtext=<lat>,<lon>&rtt=auto
```

- `lat` **первый**, потом `lon` — **наоборот**, чем в 2ГИС.
- `rtt=auto` — автомобильный (`mt` — общественный, `pd` — пешеход, `bc` — велосипед).
- Тильда перед `lat` не нужна: `rtext=~52.25,104.26` — не по документации.

**Проверено 2026-10-24:** Яндекс отвечает `Routes` (строит маршрут).

### Прочие параметры Яндекса

| Параметр | Формат | Что делает |
|---|---|---|
| `ll` | `lon,lat` | центр карты |
| `z` | 1–19 | масштаб |
| `pt` | `lon,lat` | поставить метку |
| `rtext` | `lat,lon~lat,lon` | точки маршрута |
| `rtt` | `auto/mt/pd/bc` | тип маршрута |
| `l` | `map,trf` | тип карты + пробки |

## Порядок координат — главная ловушка

| Сервис | Порядок | Пример |
|---|---|---|
| 2ГИС | **lon, lat** | `104.264909,52.251552` |
| Яндекс `rtext` | **lat, lon** | `52.251552,104.264909` |
| Яндекс `ll`/`pt` | **lon, lat** | `104.264909,52.251552` |

Один и тот же пункт читается наоборот в разных параметрах Яндекса — это самая
частая причина «ссылка открылась, но точка не та».

## Проверка без браузера

Яндекс и 2ГИС режут датацентровые IP капчей/«limited» — браузерная проверка
не работает. Проверять так:

1. **Формат** — регулярка на структуру ссылки.
2. **Смысл координат** — для Иркутска `50 < lat < 55` и `100 < lon < 108`.
   Выход за диапазон = перепутан порядок.
3. **`web_extract`** — для 2ГИС отдаёт заголовок «Как проехать до <район>, <город>»
   (значит точка распознана), для Яндекса — `Routes`. Для legacy-формата 2ГИС — `404 page not found`.

## Итог

```python
# 2ГИС
f"https://2gis.ru/directions/points/|{lon},{lat}"

# Яндекс
f"https://yandex.ru/maps/?rtext={lat},{lon}&rtt=auto"
```

Обе ссылки проверены 2026-10-24 на 10 точках Иркутска.
